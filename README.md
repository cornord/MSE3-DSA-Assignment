MSE3-DSA-Assignment

Project Description

This project implements a weighted, undirected graph representing road connections between secondary schools locations in Malawi. It uses C++ and graph algorithms to solve graph-related problems.

Programming Language

C++

Project Files

main.cpp – Main implementation of the graph algorithms.

test1.cpp to test7.cpp – Seven separate test programs covering different test scenarios.

Requirements

A C++ compiler (such as GCC or MinGW).

A computer with a C++ development environment.

How to Compile and Run

Open a terminal in the project folder.
To compile and run the main program:
g++ main.cpp -o main ./main 
To compile and run an individual test, for example:
g++ test1.cpp -o test1 ./test1 
Replace test1.cpp with any of the other test files to run a different test.
On Windows, run the generated executable using:
main.exe 

Testing

The project contains seven separate C++ test files. Each test covers a different situation to check the correctness and reliability of the implementation.
